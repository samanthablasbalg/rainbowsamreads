# Project journal

The journal records how the project changed: the context around major refactors, what was difficult
to recognize at the time, and how the development approach evolved. Entries preserve the viewpoint
of their date. Architecture Decision Records separately capture the durable rationale for individual
technical decisions, while [learning records](../learning-records/README.md) focus on one reusable
technical insight.

Entries use `YYYY-MM-DD-title.md` filenames.

- **[2026-08-12 — Why I rebuilt the frontend](2026-08-12-why-i-rebuilt-the-frontend.md)** — the
  pressures behind replacing the Angular frontend with React and what the migration revealed about
  tests, component consistency, and the project's direction.
