# Learning records

Learning records capture how a durable technical insight emerged from a concrete piece of work. They
preserve the code state, questions, and reasoning that made the lesson useful rather than presenting
it as an abstract rule. Historical records remain anchored to the implementation they investigated;
the [reference guides](../reference/README.md) are kept aligned with current code.
